# 🌱 Plant

An iOS app built with **Swift** and **SwiftUI** to help you take care of your plants.

> This is a learning project — I'm building it to learn Swift, SwiftUI and the MVVM architecture.

## ✨ Features

- Add your plants
- Track watering reminders
- Dark mode design

---

## 🛠 Built With

- **Swift**
- **SwiftUI**
- **MVVM** architecture
- **Xcode**
- Design made in **Sketch**

---

## 📂 Project Structure

```
Plant/
├── Models/        # Data models
├── Views/         # SwiftUI screens
├── ViewModels/    # Logic connecting Models and Views
└── Assets/        # Colors, images, icons
```

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/hessahmazyad/plant.git
   ```
2. Open `Plant.xcodeproj` in Xcode.
3. Choose an iPhone simulator and press **Run** (⌘R).
